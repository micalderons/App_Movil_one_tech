#Descripción del proyecto
Este proyecto consiste en una applicación móvil desarrollado con **Kotlin** y **Android Studio** para "Level Up", en nuestro caso con permiso de los profesores le cambiamos el nombre a **One-Tech** solamente. 
---
Consiste en una aplicación para vender sus productos como si fuera Mercado libre, con su Home, carro, buscar objetos, perfiles (creación de cuenta e inicio de sesión) y más parametros o cosas que debe de tener dentro de un menú despegable. Se utilizó para el repositoy GitHub para poder complementar y desarrollar de forma remota el proyecto.
---
# Las funcionalidades implementadas
- Navegación entre pantallas con `NavHost` y `BottomBar`.
- Catálogo/inicio con categorías y productos.
- Búsqueda de productos por nombre o categoría.
- Carrito con manejo de cantidad, total y vaciado.
- Registro/login/perfil con validaciones de RUT, email, contraseña, etc.
- Otros como uso de bottom bar usando `Stateflows`y `Viewmodels`. 
---
# Para poder ejecutarlo se necesita de
1. Abrir el proyecto con Android Studio.
2. Seleccionar JDK 17.
3. Seleccionar el SDK que esta puesto en la versión 36.
4. Sync gadle para descargar dependencias.
5. Elegir un **emulador** del andorid Studio para poder ejecutarlo en el `.MainActivity`.
